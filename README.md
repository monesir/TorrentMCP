# محرك بحث تورنت محلي

خدمة بحث وتحليل محلية للإيجنت: محرك Rust، وموصل لإضافات qBittorrent، وواجهة CLI بعقد JSON. الحزمة المحمولة لـWindows تضم Python وتعمل دون تثبيت qBittorrent أو Python.

## الاستخدام من الحزمة المحمولة

فك ZIP وافتح PowerShell داخل مجلد الحزمة، ثم نفذ:

```powershell
.\torrentx.exe sources
.\torrentx.exe agent --request .\examples\nirvana-agent-search.json
.\torrentx.exe agent --request .\examples\nirvana-agent-search.json --format markdown --output search-report.md
.\torrentx.exe export-markdown --input response.json --output report.md
.\torrentx.exe search "ubuntu" --limit 20
.\torrentx.exe --json search "ubuntu" --source torrentscsv,limetorrents --timeout 20
.\torrentx.exe --source-backend rust --json search "ubuntu" --source torrentscsv,piratebay
.\torrentx.exe --source-backend python --json search "ubuntu" --source torrentscsv,piratebay
.\torrentx.exe search "اسم العمل" --category tv --source limetorrents
.\torrentx.exe resolve --source limetorrents "رابط صفحة التفاصيل من نتيجة البحث"
```

الملف التنفيذي و`resources` و`runtime` أجزاء حزمة واحدة. لا تنقل الملف التنفيذي وحده. البحث يتصل بالمواقع مباشرة. فحص الوسائط يفتح بوابة قراءة مؤقتة على loopback ويغلقها عند انتهائه؛ لا ينشر خادما عاما.

## الموجود الآن

1. سجل محلي مثبت البصمات وتنفيذات Rust لـ86 إضافة من لقطة qBittorrent: 8 أساسية و78 من المجتمع العام، مع الاحتفاظ بإضافات Python الأصلية واختيار تشغيلها. المصادر الخاصة الـ28 مستبعدة. العدد يمثل الإضافات ونسخها المختلفة، لا عدد المواقع الفريدة. [المصادر والإعدادات](docs/native-sources.md) و[حالة التحقق](verification/native-ports/STATE.md).
2. بحث متواز بمهلة وإلغاء وحد نتائج لكل مصدر. `Ctrl+C` يلغي البحث والمصادر المنتظرة.
3. تقارير مستقلة للإكمال والفشل والمهلة والإلغاء والتصنيف غير المدعوم؛ تحفظ النتائج التي وصلت قبل فشل المصدر.
4. تحويل نتائج الإضافات إلى JSON داخلي مباشرة، مع حفظ UTF-8 وعلامة `|` في العنوان.
5. إزالة التكرار بالـinfohash v1 الصحيح، بما يشمل hex وbase32. تبقى ملاحظات المصادر منفصلة ولا تجمع أعداد السيدرز.
6. ترتيب النتائج بأعلى عدد سيدرز ملاحظ، ثم العنوان. هذا ترتيب إتاحة حسب بيانات المواقع، وليس تقييما لجودة إصدار الفيلم أو المسلسل.
7. الاحتفاظ بـmagnet أو رابط HTTP، واستخراج magnet من صفحات التفاصيل المدعومة. رابط HTTP وحده لا يثبت أنه رابط تنزيل torrent مباشر.
8. مكتبة Rust بعقد `SearchSource` يسمح بإضافة موصل Rust دون تغيير واجهة المحرك.
9. طلبات إيجنت JSON للبحث مع التحليل، أو تحليل تقرير محفوظ دون شبكة. يستخرج بيانات أسماء الإصدارات مع دليل كل معلومة، ويفصل المطابق والمجهول والمستبعد، ويرتب حسب تفضيلات معلنة. التفاصيل في [عقد الإيجنت](docs/agent-contract.md).
10. فحص الوسائط بواسطة ffprobe المضمن: ملفات محلية أو نطاقات من خدمة تنزيل محلية مستقلة، بسقف قراءة ومهلة وإلغاء. يعيد خصائص الفيديو والصوت والترجمة والبتريت المتاح وتوصية بالمسارات المطلوبة. [العقد والأمثلة](docs/media-inspection.md).

## الحدود الحالية

مع `TORBOX_API_KEY` تقرأ ملفات التورنتات المخزنة لدى TorBox من خوادمه، والباقي من القرناء تلقائيا. [الدليل](docs/torbox.md).

`find` يجمع البحث والفحص والمقارنة في طلب واحد. "الأفضل" يحدده الإيجنت بشروطه وتفضيلاته، ومنها صيغة الإصدار: remux أو webdl وغيرها. [العقد](docs/agent-contract.md).

`serve` يشغل خدمة محلية دائمة تبقي المصادر وجلسة rqbit جاهزة، و`agent` يمرر طلبه إليها تلقائيا عند تطابق الإعدادات، وإلا ينفذ داخل العملية. `daemon status` و`daemon stop` لإدارتها. [النقل والأمان والقياس](docs/daemon.md).

أضيف المسار المحلي `torrent_files` ثم `inspect_torrent_file`: يحل مرجع نتيجة البحث، يعيد كتالوج الملفات بهوية التورنت، ويفحص الملف الذي يختاره الإيجنت صراحة. يشغل rqbit كجلسة مشتركة تحفظ metadata وتفحص عدة ملفات بالتوازي، وتحذف بياناتها الجزئية عند الإغلاق. [الاستخدام والعقد](docs/torrent-workflow.md). تحسين السرعة وتنزيل الملفات بالكامل كوظيفة مستمرة لم ينفذا.

الإصدار 0.6 يضيف `compare_media` لمقارنة تقارير فحص محفوظة دون شبكة أو runtimes، و`analysis` الاختياري مع `inspect_torrent_file` لتقييم الملف فور فحصه. يفصل شروط القبول عن تفضيلات الترتيب، ويحفظ المطابق والمستبعد وغير المحسوم مع أسباب وأدلة؛ لا يقيس الجودة الإدراكية. [العقد والأمثلة](docs/media-comparison.md).

تقارير Markdown قابلة للقراءة البشرية ومبنية على عقد JSON نفسه، بجداول مستقلة للفيديو والصوت والترجمة وأسباب المطابقة. يدعم agent اختيار --format و--output، وexport-markdown تحويل التقارير المحفوظة. [دليل التصدير والقياس](docs/markdown-reports.md).

تحليل البحث يعتمد أسماء الإصدارات وبيانات المواقع؛ فحص الملف عملية مستقلة باسم inspect_media، أو inspect_torrent_file للفحص عبر محرك التورنت المستقل. لا يثبت المحرك اكتمال الحلقات من كلمة Complete. الإيجنت يزود الهدف وأسماءه البديلة وشروطه. MCP لم ينفذ بعد. البحث والحل يعيدان magnet أو مرجع HTTP؛ بعض المصادر تحتاج `post_form`. لا يجلب البحث نفسه محتوى ملفات الأفلام أو المسلسلات. نجاح اختبارات النقل لا يضمن توافر المواقع الحية أو تخطي حمايتها.

قائمة الإضافات الأولية مدققة ومحلية؛ لا يوجد تنزيل أو تحديث تلقائي لكود إضافات عشوائية. عامل Python عملية مستقلة لإدارة الأعطال والمهل، وليس sandbox للصلاحيات. الموصلات الجديدة يجب أن تلتزم بعقد الإلغاء والمهلة، وأن تختبر قبل اعتمادها.

`--source-backend auto` هو الاختيار الافتراضي: يستخدم Rust عند توافره، ويحتفظ بمشغل Python للإضافات الأخرى. `rust` يطلب التنفيذ الأصلي صراحة ويظهر `unsupported` للإضافة غير المنقولة؛ `python` يشغل ملفات التوافق الأصلية. لا تعني `auto` إعادة محاولة طلب فاشل عبر Python تلقائيا. الخيار السابق `--limetorrents-backend` يبقى تجاوزا خاصا لذلك المصدر. تضم الحزمة المحمولة مكتبات توافق Python المثبتة بالبصمات؛ يمكن تجهيزها للتطوير بواسطة `scripts/vendor-python-runtime.py` على نسخة من بيئة Python المضمنة. Jackett مصدر اختياري يحتاج إعداد الخدمة والمفتاح محليا في `resources/qbit/engines/jackett.json` ولا يحول المحرك إلى عميل ملزم بخدمة خارجية.

## مخرجات JSON وحالات الخروج

تقرير البحث يحمل `schema_version: 1` و`query` و`category` و`partial` و`sources` و`results`. لكل نتيجة `reference` و`observations` تحفظ المصدر والحجم والسيدرز ووقت الرصد. الحقول المجهولة `null`.

- `0`: المصادر المختارة اكتملت، حتى إذا لم تجد نتائج.
- `1`: فشل التشغيل أو لم يكتمل أي مصدر.
- `2`: خطأ في صيغة أمر CLI.
- `3`: نتائج جزئية مع مصدر واحد مكتمل على الأقل.
- `130`: إلغاء البحث بـCtrl+C.

بلوغ حد النتائج يظهر `limited: true` للمصدر، ولا يعد فشلا. التصنيف غير المدعوم يظهر صراحة في تقرير المصدر.

## التطوير والتحقق

يلزم Rust وPython وffprobe عند تشغيل جميع اختبارات التطوير. لا يلزم qBittorrent؛ ملفات الموصل المختارة موجودة داخل المستودع.

```powershell
cargo test --locked
cargo run -- --assets resources --python python --json search "ubuntu" --limit 10
cargo run -- --assets resources --python python sources
```

يمكن ضبط `TORRENT_SEARCH_TEST_PYTHON` و`TORRENT_SEARCH_TEST_FFPROBE` إلى مسارين صريحين للاختبارات. اختبارات العمليات والقراءة تستخدم عينات مضبوطة للأعطال والمهل والتوافق؛ دليل ملفات الوسائط الفعلية محفوظ في verification ولا يعد اختبارا لجودة الصورة الإدراكية.

## إضافة مصدر

لمصدر Rust، نفذ `SearchSource` وسجل مثيله في المحرك. لمصدر Python، أضف ملف الإضافة إلى `resources/qbit/engines` ثم تعريفه وبصمته وتصنيفاته وقدرته على حل HTTP إلى `sources.json`. يطابق اسم الملف `id`؛ يسمح `class_name` بالحفاظ على الصنف الأصلي عند وجود نسخ متعددة منه.

`SourceDescriptor` يصف المصدر، و`SourceOutcome` يعيد تقريره ونتائجه الجزئية. تفشل الإضافة ذات البصمة المتغيرة بصورة مستقلة. تغير أحد ملفات التوافق المشتركة يتطلب تحديثا مقصودا لبصمته بعد التحقق.

## إنشاء الحزمة المحمولة

```powershell
.\scripts\package-windows.ps1
```

يشغّل المسار الاختبارات ويبني release ويجمع الموارد والرخص، ثم يكتب ZIP وبصمته داخل dist. يحمل Python الرسمي 3.14.8 ويتحقق من [بصمته المنشورة](https://www.python.org/downloads/release/python-3148/). يجمع ffprobe من المسار المثبت أو من `-FFprobePath` مع DLLs وLICENSE وREADME.txt الأصليين وبصمات الملفات. الحزمة الناتجة لا تحتاج تثبيت Python أو FFmpeg. يرفض الكتابة فوق مخرج قائم؛ استخدم `-Destination` لمسار جديد داخل dist.

تفاصيل الدليل السابق وإعادة الاستخدام في [فحص qBittorrent](research/qbittorrent/README.md)، ونسب المكونات في [إشعارات المصادر](THIRD_PARTY_NOTICES.md).


يدعم مسار التغليف `-TargetDirectory` لاختيار مجلد بناء مستقل. يجمع فقط ملفات الإضافات المثبتة في السجل، ويستبعد إعدادات Jackett وRutor وملفات cookies والسجلات المحلية. يرفق مصدر Rust والرخص ونسخ مكتبات توافق Python وبصماتها.
