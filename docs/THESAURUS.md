## Terms

### تقييم الوسائط
- **Definition**: مطابقة شروط الإيجنت مع بيانات الملف والمسارات المفحوصة، مع أسباب ومجهول صريح؛ لا يقيس جودة الصورة الإدراكية.

### طلب تقييم الوسائط
- **Definition**: شروط قبول ملف الوسائط وتفضيلات ترتيب المرشحين المفحوصين.

### قيود الوسائط
- **Definition**: شروط إلزامية على أبعاد الفيديو وترميزه وبتريته وحجم الملف ولغات الصوت والترجمة؛ المجهول لا يثبت المخالفة.

### تفضيلات الوسائط
- **Definition**: ترتيب صريح لأهمية الخصائص المرغوبة؛ لا تستبعد النسخة ولا تحول البتريت إلى تقدير جودة.

### مقارنة الوسائط
- **Definition**: تقييم وترتيب تقارير فحص محفوظة وفق شروط وتفضيلات مشتركة، مع حفظ الهوية والأدلة لكل مرشح.

### مرشح مفحوص
- **Definition**: معرف مقارنة فريد وتقرير فحص تورنت محفوظ، مع اختيار مسار فيديو صريح عند الحاجة.

### خدمة التورنت
- **Definition**: عملية محلية مستقلة توفر بيانات الملفات وقراءة نطاقاتها للفاحص؛ لا تنفذ البحث أو تقييم الإصدارات.

### كتالوج التورنت
- **Definition**: هوية تورنت مثبتة من بياناته، مع مرجع البحث والمرجع المحلول وقائمة ملفاته المفهرسة.

### ملف التورنت
- **Definition**: فهرس ومسار وحجم ملف داخل تورنت محدد؛ يختار الإيجنت فهرسه صراحة قبل الفحص.

### تشغيل خدمة التورنت
- **Definition**: مسار محرك الخدمة المستقل ومجلد تخزين عمليات الفحص المحلي.

### تقرير عملية التورنت
- **Definition**: كتالوج متحقق منه وملف مختار وفحص وسائط عند توفره، مع حالة إغلاق عملية الخدمة.

### حدود خدمة التورنت
- **Definition**: المهلة المحدودة لجلب البيانات وتهيئة قراءة الملف وإجراء الفحص.

### بيانات التورنت
- **Definition**: الهوية وقائمة الملفات التي تقرؤها خدمة التورنت من بياناته قبل ربطها بمرجع البحث.

### تقرير Markdown
- **Definition**: تمثيل بشري لعقد JSON نفسه، بجداول ووحدات وأسباب واضحة، مع إبقاء المجهول ومصدر الادعاءات دون ترقية الثقة.

### طلب فحص الوسائط
- **Definition**: مصدر ملف واحد وحدود قراءته ولغات المسارات المطلوبة؛ لا يطلق تنزيل تورنت.

### مصدر بايتات الوسائط
- **Definition**: ملف محلي عادي أو رابط HTTP على loopback من خدمة تنزيل مستقلة، يدعم قراءة نطاقات بايتات ملف واحد بحجم معلوم.

### حدود فحص الوسائط
- **Definition**: مهلة وسقف صارم لبايتات المحتوى المقروءة عبر البوابة، مع سقف منفصل لمخرجات ffprobe.

### تقرير فحص الوسائط
- **Definition**: خصائص الحاوية والمسارات كما قرأها ffprobe، وإحصاء القراءة وحدود الفحص؛ لا يثبت سلامة الملف كاملا أو جودة الصورة الإدراكية.

### مسار الوسائط
- **Definition**: مسار فيديو أو صوت أو ترجمة أو مرفق داخل الحاوية، بفهرسه وخصائصه ووسومه المتاحة.

### قيمة خاصية الوسائط
- **Definition**: قيمة اختيارية مع أساسها: مبلغة من الحاوية أو ffprobe أو مشتقة من تنسيق البكسل، والمفقود مجهول.

### اختيار المسارات
- **Definition**: توصية بالمسارات المطابقة للغات المطلوبة، والمسارات الزائدة وغير المحسومة؛ لا تحذف مسارات ولا تعيد ترميزها.

### بوابة القراءة المحدودة
- **Definition**: خادم HTTP مؤقت على loopback لعملية ffprobe واحدة، يترجم طلبات النطاق إلى مصدر البايتات ويوقف القراءة عند السقف أو الإلغاء.

### أهلية النتيجة
- **Definition**: قرار أهلية بحسب شروط الإيجنت والأدلة المستخدمة في المسار، من أسماء الإصدارات أو بيانات الفحص؛ القيم eligible وexcluded وuncertain لا تقيس جودة الصورة الإدراكية.

### ادعاء مستخرج
- **Definition**: قيمة مستخرجة من نص المصدر مع دليل القاعدة والرمز اللذين أنتجاها.

### تقييم الشرط
- **Definition**: نتيجة مطابقة شرط معين مع السبب والقيمة المطلوبة والقيم المرصودة.

### تحليل الإصدار
- **Definition**: حقائق الإصدار والنصوص الأصلية والمصححة وآثار إصلاحها دون تغيير مراجع التنزيل.

### تغطية الحلقات
- **Definition**: مجال حلقات شامل البداية والنهاية يدعيه عنوان الإصدار، وليس تحققًا من ملفات الحزمة.

### حقيقة الإصدار
- **Definition**: حقل تحليلي يميز المجهول والادعاء الصريح والاستنتاج وتعدد القيم المحتمل.

### دليل الاستخراج
- **Definition**: المصدر وفهرس عنوانه والرمز الملاحظ وقاعدة الاستخراج.

### طلب الإيجنت
- **Definition**: مستند JSON بإصدار يطلب البحث أو التحليل أو بيانات التورنت أو فحص ملف أو مقارنة فحوص محفوظة.

### طلب التحليل
- **Definition**: هوية العمل المطلوبة وشروط القبول وتفضيلات ترتيب الإصدارات.

### قيود الإصدار
- **Definition**: شروط إلزامية؛ المخالفة تستبعد، والمعلومة الناقصة تترك الأهلية غير محسومة.

### تفضيلات الإصدار
- **Definition**: أولويات ترتيب معلنة لا تستبعد النتائج ولا تحول المجهول إلى معلوم.

### هدف البحث
- **Definition**: عنوان العمل وأسماؤه البديلة والسنة والجزء والموسم والحلقات التي يحددها الإيجنت.

### إضافة qBittorrent
- **Definition**: موصل Python يتبع واجهات البحث المستخدمة في إضافات qBittorrent.

### حدود البحث
- **Definition**: سقوف زمن التنفيذ والتوازي والنتائج ومخرجات العمليات.

### حالة المصدر
- **Definition**: النتيجة التشغيلية المستقلة لمصدر، بما يشمل الإكمال والفشل والمهلة والإلغاء وعدم دعم التصنيف.

### طلب البحث
- **Definition**: كلمات البحث والتصنيف والمصادر التي اختارها المستدعي.

### مرجع التورنت
- **Definition**: magnet أو رابط HTTP صادر عن المصدر، وقد يحتاج رابط HTTP إلى حل بواسطة المصدر.

### مصدر البحث
- **Definition**: موصل مستقل يقدم عمليات البحث وحل المراجع؛ يمكن تنفيذه بـRust أو عبر إضافة Python.

### مصدر LimeTorrents
- **Definition**: موصل Rust يتعامل مع بحث LimeTorrents وصفحات تفاصيله مباشرة، مع الاحتفاظ بهوية المصدر وعقده المشترك.

### مصدر أصلي
- **Definition**: موصل مصدر بحث ينفذ طلباته وتحليل استجاباته في Rust دون تشغيل إضافة Python؛ يحتفظ بهوية المصدر الأصلية.

### تنفيذ المصدر
- **Definition**: اختيار Rust أو Python أو التفضيل التلقائي للتنفيذ الأصلي عند توافره؛ لا يغير اختيار المواقع نفسها.

### ملاحظة المصدر
- **Definition**: بيانات نتيجة كما ادعاها مصدر معين، مع هوية المصدر ووقت رصدها.

### محرك البحث
- **Definition**: منسق المصادر وتوحيد النتائج مع الحفاظ على نجاحها وفشلها بصورة مستقلة.

### نتيجة البحث
- **Definition**: تورنت مرشح مع مرجعه وملاحظات المصادر التي عثرت عليه.

### نتيجة تشغيل المصدر
- **Definition**: تقرير تشغيل مصدر مع النتائج الجزئية التي استطاع إرجاعها.

### تقرير البحث
- **Definition**: النتائج المجمعة وتقارير جميع المصادر المختارة.

### تقرير المصدر
- **Definition**: حالة المصدر ومدته وعدد نتائجه وحدوده وتشخيص فشله عند وجوده.

### تعريف المصدر
- **Definition**: الهوية المستقرة للمصدر واسمه وتصنيفاته وقدرات حل المراجع الخاصة به.

## Forbidden

لا توجد مصطلحات محظورة إضافية في هذه المرحلة.

## Legacy

لا توجد تسميات قديمة في هذه المرحلة.

## Unresolved

لا توجد مسائل تسمية معلقة.
