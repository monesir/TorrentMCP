## ما تحقق فعليا

1. نجح اختبارا هويات التورنت وثمانية اختبارات تكامل للعمليات والمصادر: 10 اختبارات، دون اختبارات متجاهلة. شغّل مسار التجميع الاختبارات باستخدام CPython 3.14.8 المضمن في الحزمة.
2. نجح بناء Rust release لـWindows x64. يضبط المستودع CRT الثابت لهذا الهدف.
3. فك ZIP إلى مسار جديد، ثم شغلت النسخة المفكوكة. اقتصر PATH على System32، وضبط PYTHONHOME وPYTHONPATH عمدا على مسارات غير موجودة.
4. أعاد بحث `ubuntu` عشر نتائج من كل مصدر، أي 20 نتيجة. اكتمل LimeTorrents في 1811ms وTorrents CSV في 1106ms. البحث متواز، والأزمنة ملاحظة لهذا التشغيل فقط.
5. نجح اختيار رابط تفاصيل من الناتج وتمريره إلى أمر `resolve`، وإرجاع magnet ذي infohash v1 صحيح الصيغة.
6. لم يستدع المنتج qBittorrent، ولم ينزل محتوى تورنت أو يفتح خادم HTTP.

## الأدلة

- `windows-smoke.json`: ملخص بيئة الاختبار وحالات الخروج وتقارير المصدرين.
- `windows-live-search.json`: تقرير البحث الفعلي الكامل.
- `windows-live-resolution.json`: المرجع الذي أعاده حل صفحة التفاصيل.
- داخل الحزمة `package-info.json`: بصمات البناء ومصدر runtime ونتائج الفحوص المطلوبة قبل التجميع.
- سجل التجميع المحلي: `.cache/package-windows-retry.log`.

الاختبارات المصطنعة تتحقق من الأعطال والمهل والإلغاء والحدود وحفظ النتائج الجزئية والبصمات وUTF-8 وإزالة التكرار؛ لا تقدم كدليل على جودة توصيات الأفلام. الاختبار الفعلي يثبت عمل المسار على هذا الجهاز بعد استبعاد Python النظام من PATH، ولا يمثل اختبار جهاز Windows نظيف أو منصات أخرى.

الإصدار 0.1.0 لا يتضمن تحليل الإصدارات المتقدم أو MCP أو خدمة تنزيل المحتوى. لم ينشر أي مكون للعامة.
