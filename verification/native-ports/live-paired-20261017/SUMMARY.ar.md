# تجربة جميع المصادر بالبحث نفسه

جُربت الإضافات العامة الـ86 في الحزمة النهائية عبر Rust ثم Python بعبارة `nirvana in fire`، والفئة `all`، ومهلة 20 ثانية لكل مصدر وحد 20 نتيجة وتوازٍ 6. كل مشغل أعاد تقريرًا لجميع المعرفات الـ86. لم تُنزّل ملفات فيديو أو محتوى تورنت.

| المقياس | Rust | Python |
|---|---:|---:|
| اكتملت وفق تقرير المشغل | 35 | 39 |
| فشلت | 51 | 42 |
| انتهت المهلة | 0 | 5 |
| إضافات أعادت عناوين متعلقة بالمسلسل | 8 | 9 |
| نتائج فريدة ذات عناوين متعلقة بعد الدمج | 55 | 88 |
| نتائج فريدة بعناوين غير متعلقة | 24 | 24 |
| الزمن الكلي المرصود | 34.762 ثانية | 60.346 ثانية |

المطابقة هنا مبنية على العنوان: Nirvana in Fire أو Lang Ya Bang أو 琅琊榜، وتشمل الجزأين؛ ليست تحققًا من محتوى الملفات. عدادات المصدر قد تشمل نتائج مكررة قبل الدمج، وقد بقيت نتائج جزئية من مصادر فشلت أو انتهت مهلتها. تشغيل التجربتين كان متعاقبًا على الإنترنت؛ أزمنة الشبكة والكاش وتغير الموقع تمنع اعتبار ذلك مقارنة سرعة مضبوطة.

Jackett غير مهيأ في المشغلين. نسخة Python أعادت صف رسالة خطأ للمفتاح يتضمن عبارة البحث، وصنفته كمكتمل. استُبعد هذا الصف من الأرقام المتعلقة بالمسلسل؛ لذلك 39 مكتملًا في التقرير لا تعني 39 مصدرًا سليمًا. كذلك بعض إضافات Python تبتلع خطأ HTTP وتعلن نتيجة فارغة، فلا يكفي عدد completed للحكم.

| الإضافة | نتائج Rust الفريدة | نتائج Python الفريدة | الملاحظة |
|---|---:|---:|---|
| limetorrents | 20 | 20 | 19 من 20 عنوانًا متعلقًا في كل مشغل. |
| piratebay | 3 | 3 | عناوين متعلقة في المشغلين. |
| thepiratebay | 3 | 3 | عناوين متعلقة في المشغلين. |
| torrentdownload | 0 | 20 | فرق حي يحتاج فحصًا: Rust صفر، Python عشرون. |
| snowfl | 6 | 0 | Rust أعاد ست نتائج؛ Python فشل HTTP503. |
| snowfl_community_052 | 6 | 6 | عناوين متعلقة في المشغلين. |
| bitsearch | 0 | 20 | Rust أعاد HTTP520؛ Python أعاد عشرين نتيجة ثم انتهت المهلة. |
| torrentdownloads | 9 | 16 | Rust احتفظ بتسع نتائج ثم فشل: Invalid torrent reference؛ Python احتفظ بست عشرة ثم انتهت المهلة. |
| thepiratebay_community_059 | 3 | 3 | عناوين متعلقة في المشغلين. |
| torrentdownload_community_066 | 19 | 20 | 19 مقابل20 بعد الدمج؛ نسخة Python تضمنت نص إعلان ملتصقًا بأحد العناوين. |

مصادر مثل AcademicTorrents وAnimeTosho (نسخة xyz) وFitGirl أعادت نتائج، لكن العناوين المرصودة تخص بيانات Wikipedia أو Kaguya-sama أو Techtonica، واستُبعدت من النتائج المتعلقة بالمسلسل. لا تعني النتيجة الفارغة أن الموقع يعمل؛ وقد سجلت التجربة أخطاء DNS/TLS وHTTP403/404/425/429/5xx، وفروق تحليل ومراجع، إضافة إلى مهلات Python.

لم تُعدّل تنفيذات المصادر أثناء هذه التجربة. هذه نتائج اختبار حي تكشف أن نجاح مقارنة البروتوكولات المحكومة لا يكفي لإثبات التكافؤ على كل موقع حالي.
