# PC & Console Games (Strict Megathread Rules)

Read this before searching or downloading any game.

## 1. Safety First: The Megathread Policy
Games are executable code (`.exe`, `.bat`, installers, cracks, DLLs). Downloading games from random torrent sites is a high security risk.
Therefore, **ONLY** download from verified and trusted sources approved by:
- **r/Piracy Megathread:** https://www.reddit.com/r/Piracy/wiki/megathread/games
- **r/PiratedGames Megathread:** https://rentry.org/pgames

## 3. Blacklisted & Dangerous Sources (STRICTLY FORBIDDEN)

Never recommend or download games from:
- ❌ **The Pirate Bay (`thepiratebay`)**: Full of malware, trojans, and malicious game executables.
- ❌ **1337x (for games)**: Blacklisted by r/PiratedGames for distributing tainted game releases and miners.
- ❌ **IGG-Games / PCGamesTorrents**: Known for injected DRM, custom adware, and malicious redirects.
- ❌ **SteamUnlocked**: Distributes slow, untrusted, and stolen uploads.
- ❌ **Ocean of Games / AimHaven / Apkafe**: Malicious payloads and modified installers.

## 4. Search Configuration for Games

When the user asks for a game:
- Use `category: "games"`.
- Explicitly constrain sources to whitelisted providers:
  `sources: ["fitgirl_repacks", "dodi_repacks", "goggames", "onlinefix"]`
- Distinguish between **Repack** (smaller download, longer install) and **Clean Steam / GOG** (faster install, uncompressed).
- Always verify game version and included DLCs/updates.
